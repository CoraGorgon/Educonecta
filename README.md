## Ejecución
1. Descargar o clonar el repositorio.
2. Abrir `index.html` en un navegador.
3. Usar el menú para ir a las secciones del prototipo.

## Vistas representadas en un solo HTML
Por el alcance actual del curso, las vistas se representan como secciones dentro de `index.html`:
- Inicio
- Login
- Registro
- Panel del estudiante
- Consulta de vacantes

## Mapa de navegación
Inicio -> Login / Registro -> Panel -> Vacantes

## Matriz de trazabilidad
| Requerimiento | Sección | Evidencia |
|---|---|---|
| RF-01 Registrar usuario | `#registro` | Formulario de registro |
| RF-02 Iniciar sesión | `#login` | Formulario de acceso |
| RF-03 Consultar información | `#vacantes` | Tabla de vacantes simuladas |
| RF-04 Consultar panel | `#dashboard` | Tarjetas de perfil, CV y postulaciones |
| RNF-01 Responsividad | Todas | Media queries en `css/styles.css` |

## Uso de IA
Se utilizó un asistente de IA como apoyo para organizar el prototipo, generar una base de código y documentar la actividad. El equipo debe revisar y poder explicar el código entregado.
